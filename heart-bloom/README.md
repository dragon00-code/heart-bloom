# 贪吃蛇游戏说明书

这是一个基于 `Node.js + 原生 HTML/CSS/JavaScript` 的经典贪吃蛇小游戏。

## 1. 环境要求

- 已安装 Node.js
- 本地可使用 `npm`

## 2. 怎么启动

在项目根目录打开终端，执行：

```bash
HOST=0.0.0.0 PORT=3000 npm start
```

启动成功后，终端会输出类似下面的地址：

```bash
Snake server running at http://0.0.0.0:3000
```

然后用浏览器打开这个地址即可开始游戏。

如果 `3000` 端口已被占用，可以换一个端口启动：

```bash
HOST=0.0.0.0 PORT=3001 npm start
```

这时在浏览器打开：

```bash
http://0.0.0.0:3001
```

## 3. 怎么玩

打开页面后，游戏会自动开始。

你的目标是控制蛇移动，吃到食物，让分数不断增加，同时避免撞墙或撞到自己。

## 4. 操作方式

支持键盘和页面按钮两种操作方式。

键盘操作：

- `↑` / `W`：向上
- `↓` / `S`：向下
- `←` / `A`：向左
- `→` / `D`：向右
- `空格`：暂停 / 继续
- `Enter`：游戏结束后重新开始

页面按钮：

- `Pause`：暂停或继续
- `Restart`：重新开始
- `Up / Down / Left / Right`：控制移动方向

## 5. 游戏规则

- 蛇每吃到一个食物，身体会变长一格
- 每吃到一个食物，分数加 `1`
- 不能直接反向移动
  - 比如正在向右时，不能立刻改成向左
- 撞到边界，游戏结束
- 撞到自己的身体，游戏结束

## 6. 页面信息说明

页面上会显示两项状态：

- `Score`：当前分数
- `Status`：当前状态

`Status` 可能显示：

- `Running`：游戏进行中
- `Paused`：已暂停
- `Game over`：游戏结束

## 7. 测试命令

如果想验证游戏核心逻辑是否正常，可以运行：

```bash
npm test
```

当前项目测试已覆盖：

- 蛇正常移动
- 吃到食物后增长并加分
- 反方向移动限制
- 撞墙结束
- 撞到自己结束
- 食物不会生成在蛇身上

## 8. 项目结构

主要文件说明：

- `index.html`：游戏页面结构
- `styles.css`：页面样式
- `src/app.js`：页面交互、键盘控制、渲染逻辑
- `src/game.js`：游戏核心规则
- `server.js`：本地静态服务器
- `test/game.test.js`：游戏逻辑测试

## 9. 一句话快速开始

```bash
HOST=0.0.0.0 PORT=3000 npm start
```

浏览器打开本地地址后，用方向键或 `WASD` 控制蛇移动，吃食物得分，别撞墙、别撞自己。
